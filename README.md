# ML Risk-Scoring System Portfolio Project

## Overview
This comprehensive portfolio project demonstrates the development, deployment, and impact of an enterprise-grade machine learning risk-scoring system for multinational corporations across East Africa.

### 1. **Project Documentation** (ML_Risk_Scoring_Portfolio_Project.docx)
A detailed 20+ page case study covering:
- Executive Summary
- Problem Statement & Business Context
- System Architecture & Design
- Data Pipeline & Feature Engineering (150+ features)
- ML Model Development (Ensemble: XGBoost + Neural Network + Isolation Forest)
- Implementation & Deployment Strategy
- Results & Business Impact
- Technical Code Samples
- Lessons Learned & Future Enhancements

**Key Achievements Highlighted:**
- 89.3% model accuracy

- Multi-jurisdictional deployment (Kenya, Uganda, Tanzania, Rwanda, Zambia)
